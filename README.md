# MyPaint — 나만의 그림판

Windows 그림판을 따라 만든 MFC 대화 상자 기반 그림판입니다.
그림판에 없는 나만의 기능으로 **실시간 그림 공유(라이브 드로잉)** 를 더했습니다. 내가 그리는 과정을 같은 네트워크의 다른 사람들이 실시간으로 지켜보고 채팅할 수 있습니다.

- 개발 환경: Visual Studio 2022 (v143), C++17, MFC (정적 링크), x64
- 외부 라이브러리 없음: C++ 표준 라이브러리, MFC, Windows SDK(GDI/GDI+, Winsock)만 사용

## 1. 빌드와 실행

```powershell
msbuild MyPaint.sln /t:Rebuild /p:Configuration=Release /p:Platform=x64
# → x64\Release\MyPaint.exe
```

- MFC와 C++ 런타임을 정적으로 링크했으므로 `MyPaint.exe` 하나만 있으면 다른 PC에서도 실행됩니다.
  (`dumpbin /dependents`로 확인한 결과 Windows 기본 DLL만 사용합니다.)
- 그림 파일을 실행 파일에 끌어다 놓거나 명령줄 인수로 넘기면 그 파일을 열면서 시작합니다.

## 3. 나만의 아이디어: 실시간 그림 공유 (라이브 드로잉)

### 3.1 기능 소개

**"내가 그리는 장면을 다른 사람에게 실시간으로 보여 주는" 기능**입니다.

방장이 공유를 시작하면 같은 네트워크의 다른 MyPaint 사용자(최대 8명)가 방에 들어와, 방장이 그림을 그리는 과정을 **선 하나 그어지는 순간부터** 그대로 지켜볼 수 있습니다. 보는 사람들은 그림을 바꿀 수 없고(보기 전용), 오른쪽 창에서 방장과 채팅할 수 있습니다.

**이런 상황을 생각하며 만들었습니다**

- 수업이나 스터디에서 선생님이 그리는 그림/도식을 학생들이 각자 화면으로 보기
- 그림을 그리면서 친구에게 실시간으로 의견을 받기 (화면 공유 프로그램 없이)
- 그림 그리는 과정을 보여 주는 간단한 "라이브 드로잉"

일반 화면 공유와 달리 **화면 픽셀이 아니라 그림 편집 내용(명령)** 을 보내므로 데이터가 적고, 보는 사람은 자기 화면에서 **확대/축소와 스크롤을 자유롭게** 하면서 볼 수 있습니다.

### 3.2 화면 구성

| 위치 | 내용 |
| --- | --- |
| 리본 오른쪽 끝 **[공유]** 버튼 | 누르면 공유 시작/참가 메뉴. 공유 중에는 초록색 **"공유 중 ▾"**, 보는 중에는 파란색 **"보는 중 ▾"** 으로 바뀌고 끝내기/나가기 메뉴가 나옴 |
| 리본 **[채팅]** 버튼 | 오른쪽 참가자·채팅 창 보이기/숨기기 |
| 메뉴 **공유(S)** | 공유 시작, 공유 참가, 공유 끝내기/나가기, 참가자와 채팅 창 |
| 오른쪽 창 (위) | 참가자 목록 (방장 표시, 내 이름 표시, 보는 사람 수 N/8) |
| 오른쪽 창 (아래) | 채팅 기록과 입력 칸 (Enter 또는 [보내기]). 들어옴/나감 알림도 표시 |
| 상태 표시줄 오른쪽 | `● 공유 중 · 주소:포트 · N명 보는 중` / `● OO 님의 화면을 보는 중` / `공유가 끝났습니다` |
| 창 제목 | 보는 중: `방 이름 (보는 중) - MyPaint`, 끝난 뒤: `방 이름 (공유 끝남) - MyPaint` |
| 보는 사람 캔버스 | 방장의 마우스 커서가 **빨간 화살표 + 방장 이름표**로 표시됨 |

### 3.3 사용 방법

#### 방장 (그림 공유하기)

1. 리본의 **[공유] → 공유 시작...** (또는 메뉴 **공유 → 공유 시작**)을 누릅니다.
2. **닉네임**, **방 이름**, **포트**(기본 47800)를 정하고 **[공유 시작]** 을 누릅니다.
   대화 상자에 이 PC의 IP 주소가 나오므로, 방 목록에 안 보이는 사람에게는 이 주소를 알려 주면 됩니다.
3. 오른쪽에 참가자·채팅 창이 열리고 공유가 시작됩니다. 평소처럼 그리면 모든 참가자에게 바로 보입니다.
   - 그리는 도중의 선과 도형, 끌고 있는 선택 영역, 입력 중인 글자(한글 조합 중인 글자 포함)까지 보입니다.
   - 실행 취소/다시 실행, 새로 만들기, 파일 열기, 회전/크기 조정, 캔버스 크기 변경도 모두 그대로 반영됩니다.
4. 끝낼 때는 **[공유 중 ▾] → 공유 끝내기** 를 누릅니다. 공유 중에 창을 닫으면 공유를 끝낼지 먼저 묻습니다.

#### 참가자 (그림 보기)

1. **[공유] → 공유 참가...** 를 누릅니다. (지금 그림에 저장하지 않은 변경이 있으면 먼저 저장할지 묻습니다.)
2. **닉네임**을 정하고, **같은 네트워크의 방** 목록에서 방을 고릅니다.
   - 대화 상자가 열리면 자동으로 방을 찾고, **[새로 고침]** 으로 다시 찾을 수 있습니다.
   - 목록에 없으면 아래 **직접 입력** 칸에 방장의 주소와 포트를 적습니다.
3. **[참가]** (또는 목록에서 두 번 클릭)를 누르면 방장의 현재 그림을 받은 뒤 실시간으로 이어서 봅니다.
   - 늦게 들어와도 그 순간의 그림 전체를 먼저 받으므로 처음부터 볼 필요가 없습니다.
   - 확대/축소, 스크롤, 채팅은 자유롭게 할 수 있습니다.
   - 닉네임이 이미 있으면 `준호 (2)`처럼 자동으로 번호가 붙습니다.
4. 나갈 때는 **[보는 중 ▾] → 공유에서 나가기** 를 누릅니다.
5. 방장이 공유를 끝내거나 연결이 끊기면 안내가 뜨고, **마지막 그림은 보기 전용으로 남아 [다른 이름으로 저장]으로 저장할 수 있습니다.**
   새로 만들기나 열기를 하면 평소 편집 상태로 돌아갑니다.

#### 한 PC에서 시연하기

1. `x64\Release\MyPaint.exe`를 두 번 실행합니다.
2. 첫 번째 창에서 **공유 시작**, 두 번째 창에서 **공유 참가** 를 누릅니다.
3. 방 목록에 첫 번째 창의 방이 나오므로 고르고 참가합니다. (목록에 안 나오면 주소 `127.0.0.1`, 포트 `47800` 입력)
4. 첫 번째 창에서 그리면 두 번째 창에 바로 나타납니다. 채팅도 주고받을 수 있습니다.

### 3.4 공유되는 것 / 공유되지 않는 것

| 공유됨 (방장 → 참가자) | 공유되지 않음 |
| --- | --- |
| 확정된 모든 편집 (그리기, 채우기, 도형, 텍스트, 붙여넣기, 이미지 메뉴) | 방장의 도구 선택, 색, 두께 같은 설정 (그려진 결과만 보임) |
| 그리는 중인 미리보기 (선, 도형, 선택 영역 이동, 입력 중인 글자) | 방장의 확대/축소, 스크롤 위치 (참가자가 자기 보기를 따로 정함) |
| 실행 취소/다시 실행 결과, 새로 만들기/열기, 캔버스 크기 변경 | 방장의 실행 취소 기록 자체 (참가자는 실행 취소할 수 없음) |
| 방장 마우스 커서 위치 | 참가자의 마우스 커서 |
| 채팅 (방장 ↔ 참가자 모두), 참가자 목록, 들어옴/나감 알림 | 들어오기 전의 채팅 기록 |

### 3.5 제한 사항

**역할과 권한**

- **보기 전용입니다.** 참가자는 그림을 바꿀 수 없습니다. (공동 편집은 지원하지 않음) 보는 동안에는 도구·편집·이미지 메뉴와 단축키가 막히고, 확대/축소·채팅·공유 메뉴만 쓸 수 있습니다.
- 참가자는 **보는 중에는 저장할 수 없고**, 공유가 끝난 뒤에만 마지막 그림을 저장할 수 있습니다.
- 보는 중에 새로 만들기/열기를 누르면 공유에서 나갈지 먼저 묻습니다.
- 한 MyPaint 창은 방장과 참가자 중 하나만 할 수 있습니다. (공유 중에는 참가 메뉴가 꺼짐)

**인원과 참가**

- 한 방에 **보는 사람은 최대 8명**입니다. 가득 찬 방에 들어가려 하면 "방이 가득 찼습니다. (최대 8명)" 안내와 함께 거절되고, 원래 그림 그대로 평소 상태로 돌아갑니다. 한 명이 나가면 다시 들어갈 수 있습니다.
- **비밀번호, 참가 승인, 내보내기 기능이 없습니다.** 같은 네트워크에서 방을 찾을 수 있는 사람은 누구나 들어올 수 있습니다.
- 늦게 들어온 사람은 **들어온 뒤의 채팅만** 봅니다.
- 서로 **같은 버전의 MyPaint**끼리만 연결됩니다. (버전이 다르면 이유와 함께 거절)

**네트워크**

- **같은 네트워크(LAN) 안에서만** 쓰도록 만들었습니다. 인터넷 너머의 PC와 연결하려면 방장 쪽 공유기에서 포트포워딩을 직접 설정해야 하며, 이 경우는 따로 시험하지 않았습니다.
- IPv4만 지원합니다.
- 방 찾기는 UDP 방송(포트 **47801**)을 씁니다. 공유기나 방화벽이 방송을 막는 환경에서는 목록에 안 나오므로, 방장 주소를 직접 입력해야 합니다.
- 다른 PC에서 참가하려면 방장 PC의 **Windows 방화벽**이 MyPaint를 허용해야 합니다. 처음 공유를 시작할 때 방화벽 허용 창이 뜨면 허용해 주세요. (같은 PC의 `127.0.0.1` 연결은 허용하지 않아도 됩니다.)
- 포트가 이미 쓰이고 있으면(같은 PC에서 다른 MyPaint가 같은 포트로 공유 중이거나 다른 프로그램이 사용 중) 공유를 시작할 수 없다는 안내가 뜹니다. 다른 포트를 고르세요.
- 주고받는 데이터는 **암호화하지 않습니다.** 민감한 그림은 믿을 수 있는 네트워크에서만 공유하세요.
- **자동 재연결은 없습니다.** 연결이 끊기면 안내만 뜨고, 다시 보려면 공유 참가를 다시 해야 합니다.

**성능과 크기**

- 미리보기와 커서는 약 30fps로 보냅니다. 확정된 편집은 바로 보냅니다.
- 중간에 들어온 사람에게는 그림 전체를 PNG로 압축해 보내므로, 아주 큰 캔버스(예: 수천 × 수천 픽셀)는 처음 받는 데 시간이 걸릴 수 있습니다.
- 한 참가자에게 보낼 데이터가 256MB 넘게 쌓이면(네트워크가 너무 느림) 그 참가자의 연결을 끊습니다.
- 방장 커서는 방장의 마우스가 **이미지 영역 위에 있을 때만** 보입니다.
- 글자 수 제한: 닉네임 20자, 방 이름 40자, 채팅 한 번에 300자

### 3.6 동작 원리

이 기능을 위해 처음부터 **"모든 편집은 명령(Command) 객체"** 구조로 그림판을 만들었습니다.

```
 방장 MyPaint                                         참가자 MyPaint
┌─────────────────────────┐   TCP (길이+내용 프레임)    ┌─────────────────────────┐
│ 도구 → Command → Document│ ─── 편집 명령 ───────────▶ │ Document에 기록 없이 적용  │
│  · 실행 취소/다시 실행    │ ─── 바뀐 영역 픽셀 ───────▶ │                          │
│  · 새 그림/열기/크기 변경 │ ─── 그림 전체(PNG) ───────▶ │                          │
│ 30fps 타이머             │ ─── 미리보기, 커서 ───────▶ │ 보기 전용 도구에 표시      │
│                         │ ◀── 채팅 ─────────────────  │                          │
└─────────────────────────┘                            └─────────────────────────┘
        ▲ UDP 47801 방 찾기 응답 ◀──────────────────────── 방송으로 방 찾기
```

- **편집 = 명령**: 연필 한 획, 채우기, 도형 하나가 각각 직렬화할 수 있는 `Command` 객체이고, 그림 픽셀은 `Document::Apply()`로만 바뀝니다. 방장은 적용된 명령을 그대로 보내고, 참가자는 같은 명령을 자기 문서에 실행합니다. 같은 명령은 어디서 실행해도 같은 결과가 나오도록 만들었습니다.
- **환경에 따라 결과가 다를 수 있는 작업은 픽셀로**: 텍스트(참가자 PC에 같은 글꼴이 없을 수 있음), 붙여넣기, 선택 영역 이동은 처음부터 결과 픽셀을 담은 `PatchCommand`로 기록하므로 어느 PC에서나 똑같이 보입니다.
- **실행 취소/다시 실행**은 명령이 아니라 바뀐 영역의 결과 픽셀을 보내고, 캔버스 크기가 바뀌는 경우는 그림 전체를 PNG로 보냅니다.
- **미리보기**는 바뀐 것이 있을 때만 보냅니다. 선택 영역을 끄는 동안에는 픽셀을 한 번만 보내고 이후에는 위치만 보냅니다.
- **중간 참가**: 참가하면 먼저 그림 전체(PNG)를 받고, 그 뒤부터 명령을 이어서 받습니다.
- **UI가 멈추지 않도록** 소켓 입출력은 별도 스레드(`NetEngine`)가 하고, 받은 내용은 창 메시지로 UI 스레드에 넘겨 처리합니다.

### 3.7 검증한 시나리오

한 PC에서 MyPaint 여러 개를 실행해 자동/수동으로 확인했습니다.

| 시나리오 | 결과 |
| --- | --- |
| 방 찾기 → 참가 → 미리 그려 둔 그림 받기 | 참가 즉시 방장의 현재 그림이 보임 |
| 방장이 마우스를 떼기 전 연필 선 | 참가자 화면에 실시간으로 보임 |
| 방장 실행 취소 | 참가자 화면에서도 사라짐 |
| 텍스트 입력 중 한글 조합, 선택 영역 끌기 | 참가자 화면에 실시간으로 보임 |
| 방장 커서 | 참가자 화면에 빨간 화살표와 이름표로 보임 |
| 참가자가 그리기/실행 취소 시도 | 그림이 바뀌지 않음 |
| 채팅, 들어옴/나감 알림, 같은 닉네임 | 양쪽 기록이 같음, `준호 (2)`로 바뀜 |
| 방장이 회전 (캔버스 크기 변경) | 모든 참가자 캔버스가 600×800으로 바뀜 |
| 8명이 찬 방에 9번째 참가 | "방이 가득 찼습니다" 안내 후 거절, 한 명이 나가면 참가 가능 |
| 방장이 공유를 끝냄 | 참가자에게 안내, 마지막 그림이 남고 저장 가능 |

## 4. 프로그램 구조

```
MyPaint/
├── MyPaint.cpp / MyPaintDlg.*   앱과 주 대화 상자 (메뉴·도구·캔버스·공유 연결)
├── Core/      그림 데이터와 편집 명령 (UI와 무관)
│   ├── Surface        32bpp 비트맵 (DIB Section)
│   ├── Document       문서. 픽셀을 바꾸는 유일한 통로, 변경 알림
│   ├── History        실행 취소/다시 실행 기록 (최대 100단계, 512MB)
│   ├── Command        편집 명령 기반 클래스와 직렬화
│   └── Stroke/Fill/Shape/Path/ImageCommands   각 편집 명령
├── Tools/     마우스 입력을 명령으로 바꾸는 도구들
│   └── Freehand, Fill, Picker, Magnifier, Shape, Select, Text, RemoteView(보기 전용)
├── UI/        캔버스, 도구 패널(리본), 대화 상자, 클립보드, 파일 입출력, 공유 창
└── Net/       실시간 공유
    ├── NetEngine      소켓 스레드 (TCP 서버/클라이언트, UDP 방 찾기 응답)
    ├── Protocol       메시지 형식, PNG 압축, 방 찾기 패킷
    └── ShareSession   방장(ShareHost)과 참가자(ShareViewer) 로직
```

- 도구는 드래그하는 동안 **미리보기 명령**을 만들고, 캔버스는 문서 사본 위에 그 명령을 실행해 보여 줍니다. 확정할 때도 같은 코드로 그리므로 미리보기와 결과가 픽셀 단위로 같습니다. 이 미리보기 명령을 그대로 참가자에게 보내는 것이 실시간 공유의 미리보기입니다.
