# 나만의 그림판 만들기 과제 패키지

과제 안내서와 함께 제공하는 시작 패키지입니다. 이 폴더를 그대로 GitHub 저장소로 만들어 작업하세요.

이 README는 패키지 설명입니다. 제출할 때는 본인의 README로 바꿔 주세요. 본인의 README에는 나만의 아이디어에 대한 설명이 들어가야 합니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `MyPaint.sln` | 빌드 설정과 출력 경로가 지정된 MFC 대화 상자 기반 빈 솔루션 (Visual Studio 2022, x64) |
| `MyPaint/` | 프로젝트. 빈 대화 상자 하나만 있음 |
| `.gitignore` | 빌드 결과물을 커밋하지 않도록 설정 |

## 빌드

```powershell
msbuild MyPaint.sln /t:Rebuild /p:Configuration=Release /p:Platform=x64
# → x64\Release\MyPaint.exe
```

- 빌드 결과는 `x64\Release\MyPaint.exe`입니다. 솔루션 이름, 프로젝트 이름, 출력 경로를 바꾸지 마세요.
- MFC는 정적 라이브러리로 링크하도록 설정되어 있어, 별도 설치 없이 실행 파일만으로 실행됩니다. 설정을 바꾸면 깨끗한 PC에서 실행되는지 직접 확인해 주세요.
- 소스 파일 구성, 대화 상자 구성, 추가 대화 상자와 클래스는 자유롭게 바꿔도 됩니다.
- 소스 파일은 UTF-8로 저장되어 있고 `/utf-8` 옵션으로 컴파일됩니다.
- 언어 표준은 C++17로 설정되어 있습니다. C++14 이상이면 바꿔도 됩니다.
